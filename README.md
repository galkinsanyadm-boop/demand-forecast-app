# Прогноз спроса на товары — MVP

Веб-сервис для прогнозирования спроса на товары на 7–14 дней вперёд. Сделан по кейсу «Нейросетевая модель для прогнозирования спроса на товары».

## Что внутри

- **Frontend:** Streamlit + Plotly (4 интерактивные вкладки)
- **ML:** `LinearRegression` (бейзлайн) и `MLPRegressor` (нейросеть 64→32) — обе обучаются на той же логике, что в ноутбуке `misha-proj.ipynb`
- **Прогноз на 7–14 дней:** рекурсивный — предсказание дня *t* подставляется как `lag_1` для дня *t+1*
- **EDA:** встроенная вкладка с графиками сезонности по дням недели, месяцам, эффекту промо и праздников
- **Сценарии:** тумблеры «промо-акция» и «праздничный период» — модель пересчитывает прогноз на лету

## Метрики моделей (тест: октябрь–декабрь 2024)

| Модель | MAE | RMSE |
|---|---|---|
| Naive lag-1 | 13.27 | 17.78 |
| Seasonal lag-7 | 11.92 | 16.59 |
| Linear Regression | 8.99 | 11.37 |
| **MLP Regressor** | **7.63** | **9.73** |

Нейросеть уверенно бьёт оба наивных бейзлайна и обходит линейную регрессию.

## Запуск

### Шаг 1. Установить зависимости

```bash
python3 -m venv venv
source venv/bin/activate           # macOS / Linux
# или: venv\Scripts\activate       # Windows

pip install -r requirements.txt
```

### Шаг 2. Положить датасет

Файл `synthetic_retail_demand_dataset.csv` (тот же, что использует ноутбук) положить в папку `data/`. Альтернатива: загрузить CSV через сайдбар в интерфейсе.

### Шаг 3. Запустить

```bash
streamlit run app.py
```

Откроется в браузере на `http://localhost:8501`. Первый запуск ~10 секунд (обучаются модели и кэшируются).

## Как пользоваться

1. **Сайдбар слева** — выбор товара, горизонта прогноза (7–14 дней), модели, сценария.
2. **Вкладка «🔮 Прогноз»** — основной экран: KPI-карточки сверху, график «история + прогноз», таблица по дням.
3. **Вкладка «📊 Сравнение моделей»** — MAE/RMSE по всем 4 моделям, факт vs прогноз на тесте для выбранного товара, кривая обучения MLP.
4. **Вкладка «📈 Анализ данных»** — EDA: динамика спроса, спрос по дням недели и месяцам, влияние промо и праздников.
5. **Вкладка «📋 О проекте»** — описание стека и ограничений.

## Ограничения MVP

- Будущие значения цены / температуры / конкурентной цены берутся как среднее за последние 14 дней.
- Поле `stockout` участвует в фичах (наследовано из ноутбука) — для продакшена это нужно пересмотреть, потому что stockout «обрезает» наблюдаемый спрос.
- Используется один общий MLP на 18 товаров (item_id закодирован one-hot). Для большего числа товаров логичнее использовать эмбеддинги или отдельные модели.
